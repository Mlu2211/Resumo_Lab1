Primeiro resumo das aulas sobre Microsoft Azure, Produtos, Benefícios e Conta Estudante
Microsoft Azure- É um portal da Microsoft na nuvem com diversos produtos e serviços para otimização, customização, infraestrutura, segurança, governança e etc.
Primeira Impressão no Azure:
Um portal cheio de serviços e funções que podem ser utilizados, porém me assustou bastante saber que o Azure oferece tantos recursos. Porém o que mais gostei foi a separação de serviços e conteúdos por categorias.

Na prática:  Os recursos Iaas, Saas e Paas são gigantescos e podemos criar uma infraestrutura moderna e com segurança, para inicializar programas e armazenar VM's de diversos modelos e para diferentes tipos de serviços.

🏠 Azure App Service: Para armazenar aplicativos web.
💻 Azure Functions: Para executar código sem servidor.
📳 Azure Notification Hubs: Para enviar notificações push para aplicativos móveis.
🎲 Azure Database for MySQL: Para criar e gerenciar bancos de dados MySQL.
📊 Application Insights: Para monitorar o desempenho e diagnosticar problemas em seus aplicativos.
📚 Azure DevOps: Para colaboração em projetos de software, controle de versão (Git), integração contínua e entrega contínua (CI/CD).
​
Observações importantes:
❗Crédito Limitado: O crédito gratuito é limitado e, uma vez esgotado, seus serviços podem ser desabilitados, a menos que você faça um upgrade para uma conta paga.
❗Restrições de Serviços: Nem todos os serviços do Azure estão disponíveis gratuitamente ou com o crédito estudantil, e algumas podem ter limitações de recursos ou regiões.
